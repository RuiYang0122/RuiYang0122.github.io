# Rui Yang — Personal Homepage

Source of [ruiyang0122.github.io](https://ruiyang0122.github.io/).

Minimal academic-style personal homepage, inspired by [zhenwwang.github.io](https://zhenwwang.github.io/).

## Structure

- `index.html` — single-file site (embedded CSS/JS), light/dark theme, responsive
- `images/avatar.jpg` — profile photo

## Local preview

Open `index.html` in a browser, or run any static server:

```bash
python -m http.server 8000
```
